| 设置反馈收集流程 | D+1 | Community Manager |

### 频道结构建议

```
project-doc Discord
├── #announcements   → 发布公告
├── #general         → 一般讨论
├── #help            → 使用帮助
├── #feature-ideas   → 功能建议
├── #bugs            → Bug 报告
└── #showcase        → 使用案例分享
```

### 反馈收集流程

```
用户反馈 → Community Manager 分类 → 
├── Bug → GitHub Issue
├── 功能建议 → feature-ideas 频道讨论 → Tech Lead 评估
├── 使用问题 → #help 解答 → FAQ 文档更新
```
